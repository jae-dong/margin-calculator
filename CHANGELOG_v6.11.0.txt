리셀 PICK v6.11.0

1. 로그인 지속
- 웹 종료 후에도 마지막 접속 기준 1시간 동안 로그인 유지
- 1시간 미접속 시 자동 로그아웃
- 로그인 및 로그인 복원 후 소싱 메인 맨 위로 이동

2. 초기화 확대
- 인식 상품정보, 검색어, 매장, 가격, 계산값, KREAM/POIZON 분석, 자동 메모 전부 초기화
- 저장 기록, 계정, 이용권, 설정은 유지

3. KREAM·POIZON 영수증
- 촬영 및 사진 불러오기
- 매장명, 구매일, 상품, 수량, 금액 인식
- 리셀 영수증으로 구분 저장
- 기록 탭 및 엑셀 다운로드

4. 자동 소싱 메모
- 일반상품 및 리셀 각각 자동 작성
- 계산값 변경 시 자동 갱신
- 직접 수정 시 자동 덮어쓰기 방지
- 기록 탭 저장/삭제 및 전체 엑셀 시트 포함

5. 안내 개선
- 매입 예정가는 1차 할인이 적용된 금액을 입력하도록 명확히 표시
