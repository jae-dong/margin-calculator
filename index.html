공통 계산 설정

사용법: 실제 사업 조건에 맞게 세율·수수료·배송비를 입력하고 아래의 설정 저장 버튼을 누르세요. 플랫폼별 값은 각각 따로 저장됩니다.
사용자 상황에 맞게 직접 입력합니다. 사용하지 않으면 0%로 두세요.
특정 연봉이나 매출을 가정하지 않습니다. 세율·수수료·배송비는 각 사용자가 직접 설정할 수 있습니다.

1상품 촬영상품이나 바코드를 선명하게 찍으세요.
2판매처 확인쿠팡·네이버쇼핑 또는 KREAM·POIZON으로 이동합니다.

서비스 안내

계정 만들기

새로고침하거나 뒤로가기로 앱을 종료해도 마지막 활동 후 1시간 동안 로그인 상태가 유지됩니다. 기기에 저장된 서버 로그인키로 복원하며, 마지막 이용 후 1시간 미접속 시 자동 로그아웃됩니다.
아이디 기억은 아이디만 저장하며 비밀번호는 저장하지 않습니다. 앱을 닫아도 마지막 접속 후 1시간 동안 로그인 상태가 유지됩니다.
