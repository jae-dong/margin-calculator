이용약관

리셀 PICK · 베타 공개 문서

1. 목적

본 약관은 리셀 PICK이 제공하는 상품 소싱·사진 분석·마진 계산·기록 보관 서비스의 이용조건을 정합니다.

2. 계정

회원은 정확한 정보를 사용하고 비밀번호와 로그인 기기를 안전하게 관리해야 합니다. 계정 공유, 분석 횟수 우회, 비정상 자동화와 서비스 방해 행위는 제한될 수 있습니다.

3. 분석 결과

사진 인식, 가격 검색, 키워드 수요와 수익 계산 결과는 의사결정을 돕는 참고자료입니다. 실제 판매가, 수수료, 세금, 재고와 플랫폼 정책은 이용자가 최종 확인해야 합니다.

4. 이용권

무료 제공량과 관리자가 선물한 이용권은 화면에 표시된 조건을 따릅니다. 정식 유료결제 도입 시 가격, 갱신, 해지와 환불 조건을 별도로 고지합니다.

5. 서비스 변경과 중단

오류 수정, 보안, 외부 플랫폼 정책 또는 서버 점검을 위해 기능이 변경되거나 일시 중단될 수 있습니다. 중요한 변경은 앱 공지로 안내합니다.

6. 이용 제한

타인의 계정 침해, 서비스 악용, 불법 정보 입력, API 비용을 고의로 발생시키는 행위가 확인되면 사유를 안내하고 이용을 제한할 수 있습니다.

7. 회원탈퇴

회원은 앱 설정 또는 공개 계정 삭제 페이지에서 탈퇴할 수 있습니다. 탈퇴가 완료되면 계정 연결 데이터는 복구할 수 없습니다.
