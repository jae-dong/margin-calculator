리셀 PICK WEB v5.8.0 요금제 제공량·과다사용 방지·수익성 점검 통합본

[주요 변경]
- 베타 이용권 상태와 30일 테스트 기간 표시
- 이름/상호와 연락 이메일을 기기에 저장하는 베타 이용정보 추가
- 이용약관·개인정보 처리방침·결제/환불 기준·고객지원 초안 추가
- 실제 결제와 회원가입이 아직 연결되지 않았음을 화면에서 명확히 표시
- 고객 화면의 기술용 문구 비노출 원칙 유지
- 기존 v5.6.0 기능 전체 포함

[적용]
1. 압축을 새 폴더에 풉니다.
2. 기존 GitHub 저장소의 파일을 이 폴더 파일로 전체 교체합니다.
3. GitHub Desktop에서 Commit 후 Push합니다.
4. Render 배포 완료 후 휴대폰에서 웹앱을 완전히 종료하고 다시 실행합니다.
5. 오래된 화면이 보이면 브라우저 캐시를 지우거나 홈 화면 아이콘을 삭제 후 다시 추가합니다.

[중요]
- 이번 버전은 상용화 준비용 베타 운영 화면입니다. 실제 회원가입·서버 DB·Google Play 결제는 아직 연결되지 않았습니다.
- 약관과 개인정보 처리방침은 초안입니다. 정식 판매 전 사업자 정보, 고객지원 이메일, 가격, 무료체험, 환불조건을 확정한 뒤 최종 검토해야 합니다.
- 현재 데이터는 사용자 기기의 브라우저 저장소에 보관됩니다. 기기 변경 전 전체 데이터 백업을 사용하세요.

- 제공량 소진 시 신규 AI 호출 차단

- 운영자용 사용자 1인당 예상 AI 비용 표시
