리셀 PICK WEB v6.10.2 회원 이용권 위치 개선

변경 내용
- 설정 화면 맨 위에 있던 관리자 회원 이용권 안내를 제거했습니다.
- 관리자 운영센터 안의 회원 검색창 바로 위로 회원 이용권 안내를 옮겼습니다.
- 회원을 검색하면 검색 결과 카드에서 PRO/PRO+ 이용권과 일수를 선물할 수 있습니다.
- 이용 제한·해제 기능은 같은 회원 결과 카드에 그대로 유지됩니다.
- v6.10.1의 로그인·카메라·분석 안정화 기능은 변경하지 않았습니다.

적용 방법
1. 압축을 풉니다.
2. 폴더 안 파일을 기존 GitHub 프로젝트에 모두 덮어씁니다.
3. GitHub Desktop Summary에 아래 문구를 붙여넣습니다.
   리셀 PICK v6.10.2 회원 이용권 위치 개선
4. Commit to main → Push origin을 누릅니다.
5. Render 배포 완료 후 /version.json에서 6.10.2를 확인합니다.
