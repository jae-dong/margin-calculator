리셀 PICK WEB v6.9.3 로그인 원상복구 긴급 수정

수정 내용
- 기존에 정상 동작하던 Flask 세션 로그인 방식을 우선 사용
- 오래된 세션 쿠키가 남아 있어도 유효한 로그인 토큰을 막지 않도록 수정
- 설치형 앱에서 세션 쿠키 갱신이 늦을 때 자동 복구
- 관리자 이메일 및 회원번호 100000 로그인 유지
- 로그인 실패 원인을 로그인창에 표시
- v6.9.2의 하단 탭·설정 화면 분리·사진 분석·키워드 분석 기능 유지

적용
1. 압축을 풉니다.
2. 폴더 안의 파일 전체를 기존 프로젝트에 덮어씁니다.
3. GitHub Desktop에서 Commit to main 후 Push origin 합니다.
4. Render가 Live가 된 뒤 앱주소/version.json 에서 6.9.3을 확인합니다.
5. 휴대폰 앱을 완전히 종료한 뒤 다시 실행합니다.
