리셀 PICK v6.11.6 적용 방법

1. ZIP 안의 파일을 GitHub 저장소 최상단(app.py가 있는 위치)에 모두 덮어씁니다.
2. GitHub Desktop에서 Commit to main → Push origin을 누릅니다.
3. Render 배포가 Live가 된 뒤 앱 주소 뒤에 /version.json을 붙여 6.11.6인지 확인합니다.
4. 배포 후 최초 한 번 로그인합니다. 이번 버전부터 새 장치키가 발급됩니다.
5. 로그인 직후 새로고침 → 로그인 유지 확인
6. 뒤로가기로 웹 종료 → 1~5분 안에 다시 실행 → 로그인 유지 확인

중요
- index.html만 교체하면 안 됩니다. auth_sessions 테이블에 장치키 해시 열을 추가하므로 ZIP 전체를 덮어써야 합니다.
- 배포 직후에는 반드시 최초 한 번 다시 로그인해야 새 장치키가 생성됩니다.
- 마지막 서버 활동 후 1시간이 지나면 보안을 위해 다시 로그인해야 합니다.
