리셀 PICK WEB v5.6.0 상용화 준비 통합본

[주요 변경]
- 고객 화면에서 초절약·API 0회·캐시·토큰 등 개발자 문구 제거
- 첫 사용자용 4단계 시작 안내 추가
- 전체 데이터 JSON 백업·복원 추가
- 기기 내 데이터 전체 삭제 기능 추가
- API 비용·토큰 정보는 운영자 관리 영역으로 접어 숨김
- 고객용 서비스 이용 현황에는 이번 달 분석 횟수만 표시
- 기존 v5.5.3 기능 전체 포함

[적용]
1. 압축을 새 폴더에 풉니다.
2. 기존 GitHub 저장소의 파일을 이 폴더 파일로 전체 교체합니다.
3. GitHub Desktop에서 Commit 후 Push합니다.
4. Render 배포 완료 후 휴대폰에서 웹앱을 완전히 종료하고 다시 실행합니다.
5. 오래된 화면이 보이면 브라우저 캐시를 지우거나 홈 화면 아이콘을 삭제 후 다시 추가합니다.

[주의]
현재 데이터는 사용자 기기의 브라우저 저장소에 보관됩니다. 정식 판매 전에는 회원가입·서버 DB·구독 결제·개인정보처리방침을 추가해야 합니다.
