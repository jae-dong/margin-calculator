리셀 PICK WEB v6.9.0 적용 방법

[이번 업데이트 핵심]
1. 설정 탭의 하단 설정 카드가 다른 탭에서도 계속 보이던 HTML 구조 오류 수정
2. 설정 내용은 설정 탭에서만 표시되도록 페이지 격리 CSS를 이중 적용
3. 이메일뿐 아니라 6자리 회원번호로도 로그인 가능
4. Gmail 점(.)·플러스 별칭 차이로 ADMIN_EMAILS 관리자 권한이 누락되는 문제 수정
5. 관리자 이메일 또는 예약 관리자 회원번호 100000으로 로그인하면 손실된 관리자 권한을 즉시 복구
6. 로그인 실패 사유를 팝업이 아니라 로그인 창 안의 빨간 안내문으로 표시
7. 로그인 실패 횟수와 계정 잠금 시간을 구체적으로 안내
8. 관리자 로그인 성공 시 설정의 운영자 관리 화면으로 자동 이동
9. 사진 분석 전 썸네일 생성·바코드 확인을 병렬 처리해 대기시간 단축
10. 상품 글자와 모델번호 인식용 이미지 해상도·품질을 높이고 GPT-5 mini 실패 시 GPT-4.1 mini로 자동 전환
11. 키워드 분석의 임의 월간검색량·상품수 추정치를 제거
12. 네이버 검색광고 키워드도구 공식 API 연결 시 PC·모바일 월간 검색수와 경쟁도를 우선 표시
13. 공식 API가 연결되지 않으면 가짜 숫자를 만들지 않고 '자료부족'으로 표시
14. 공개 웹 검색은 최근 수요·리뷰·구매·가격 경쟁 신호의 교차검증에만 사용
15. 키워드 분석 캐시를 30일에서 3일로 단축해 최신성 강화
16. v6.8.0 하단 탭 터치 안정화와 v6.6.0 회원·약관·동의 이력 기능 유지

[기존 프로젝트에 적용]
1. 이 ZIP을 별도 폴더에 압축 해제
2. RESALE_PICK_v6.9.0 폴더 안의 파일 전체를 기존 margin-calculator 폴더에 덮어쓰기
3. GitHub Desktop에서 margin-calculator 저장소 선택
4. 변경 파일 확인
5. Summary 입력: 리셀 PICK v6.9.0 로그인·사진·키워드 신뢰도 개선
6. Commit to main
7. Push origin
8. Render 배포 완료 후 /version.json에서 6.9.0 확인
9. 휴대폰 앱을 완전히 종료하고 다시 실행

[Render에서 반드시 확인할 기존 환경변수]
- DATABASE_URL
- SECRET_KEY
- ADMIN_EMAILS: 관리자 가입 이메일을 정확히 입력
- OPENAI_API_KEY

[공식 키워드 검색량 연결 시 추가 환경변수]
- NAVER_SEARCHAD_API_KEY
- NAVER_SEARCHAD_SECRET_KEY
- NAVER_SEARCHAD_CUSTOMER_ID

세 값은 네이버 검색광고 API에서 발급받아 Render Environment에 입력합니다. 입력하지 않아도 앱은 작동하지만 월간 검색량은 추정하지 않고 자료부족으로 표시합니다.

[최종 검증]
- 소싱·기록·장바구니·통계 탭에서 설정 내용이 보이지 않는지 확인
- 설정 탭에서 데이터 관리와 공통 계산 설정이 정상 표시되는지 확인
- 관리자 이메일 또는 회원번호 100000으로 로그인
- 비밀번호 오류 시 로그인 창 안에 실패 문구가 표시되는지 확인
- 관리자 로그인 후 운영자 관리가 자동으로 열리는지 확인
- 상품 사진 1장과 여러 장을 각각 분석해 모델번호·바코드·상품명 확인
- 키워드 분석에서 공식 API 미연결 시 임의 검색량 숫자가 표시되지 않는지 확인
- 공식 API 연결 후 PC+모바일 월간 검색수가 표시되는지 확인

[주의]
- 기존 PostgreSQL 회원·동의 이력·클라우드 데이터는 삭제되지 않습니다.
- ADMIN_EMAILS는 쉼표로 여러 이메일을 입력할 수 있습니다.
- 네이버 개발자센터의 일부 검색·트렌드 API는 2026년 7월 말 이관·종료 예정이므로 이 버전은 종료 대상 쇼핑 검색 API가 아니라 검색광고 키워드도구 API를 사용합니다.
