리셀 PICK v6.12.1 적용 방법

1. ZIP 안의 모든 파일을 app.py가 있는 GitHub 저장소 최상단에 덮어씁니다.
2. GitHub Desktop에서 Commit to main → Push origin 합니다.
3. Render 배포가 Live가 된 뒤 /version.json에서 6.12.1을 확인합니다.
4. 이전 다중 로그인키를 제거했으므로 최초 한 번 로그인합니다.
5. 로그인 직후 새로고침 → 뒤로가기로 종료 → 1시간 안에 다시 접속 순서로 확인합니다.

중요: app.py와 index.html을 반드시 함께 교체해야 합니다.
