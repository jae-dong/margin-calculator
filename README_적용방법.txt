리셀 PICK v6.12.2 적용 방법

1. ZIP 안의 모든 파일을 app.py가 있는 GitHub 저장소 최상단에 덮어씁니다.
2. GitHub Desktop에서 Commit to main → Push origin 합니다.
3. Render가 Live가 된 뒤 /version.json에서 6.12.2를 확인합니다.
4. 최초 한 번 로그인하면 DB 저장형 로그인키가 생성됩니다.
5. 새로고침 → 뒤로가기로 종료 → 1시간 안에 재접속 순서로 확인합니다.

중요: app.py와 index.html을 반드시 함께 교체해야 합니다.
