리셀 PICK WEB v6.11.0 폭풍 업데이트 1차

주요 변경 내용
- 웹이나 홈 화면 앱을 닫았다 다시 열어도 마지막 접속 후 1시간 이내에는 로그인 상태가 유지됩니다.
- 마지막 접속 후 1시간 동안 미접속하면 자동 로그아웃됩니다.
- 로그인 성공 또는 유효 로그인 복원 후 소싱 메인화면 맨 위에서 시작합니다.
- 현재 확인 상품 초기화 시 상품명·브랜드·모델번호·바코드·용량·검색어·매장·가격·계산값·KREAM/POIZON 분석 결과·자동 메모가 모두 비워집니다.
- 저장 기록, 이용권, 계정, 설정은 현재 확인 상품 초기화로 삭제되지 않습니다.
- KREAM·POIZON 매입 예정가에는 매장·아울렛의 1차 할인이 이미 적용된 금액을 입력하도록 설명을 명확히 했습니다.
- KREAM·POIZON 탭에 영수증 촬영·사진 불러오기·자동 인식·기록 저장·엑셀 다운로드 기능을 추가했습니다.
- 일반상품과 KREAM·POIZON 양쪽에 자동 소싱 메모 기능을 추가했습니다.
- 상품정보와 계산값이 변하면 메모가 자동 갱신되며 직접 수정한 메모는 자동으로 덮어쓰지 않습니다.
- 저장한 메모는 기록 탭에서 확인·삭제할 수 있고 전체 엑셀의 '자동 소싱 메모' 시트에도 포함됩니다.
- 기존 회원 이용권 선물, 이용 제한, 관리자 무제한, 무료 월 30회, 고객센터 기능은 그대로 유지합니다.

적용 방법
1. ZIP 압축을 풉니다.
2. RESALE_PICK_v6.11.0 폴더 안의 파일을 기존 GitHub 프로젝트에 전부 덮어씁니다.
3. GitHub Desktop Summary에 아래 문구를 붙여넣습니다.
   리셀 PICK v6.11.0 로그인·초기화·영수증·자동메모 통합
4. Commit to main → Push origin을 누릅니다.
5. Render 배포 상태가 Live로 바뀔 때까지 기다립니다.
6. 앱 주소 뒤에 /version.json을 붙여 버전이 6.11.0인지 확인합니다.
7. 휴대폰 웹앱을 완전히 종료했다 다시 열어 로그인 유지와 메인화면 시작을 확인합니다.
8. 일반상품과 KREAM·POIZON 탭에서 초기화·영수증·자동 메모를 각각 한 번씩 테스트합니다.

배포 후 필수 확인
- 로그인 후 소싱 메인화면 맨 위로 이동하는지
- 웹을 종료했다 1시간 이내 다시 열었을 때 로그인 상태가 유지되는지
- 초기화 후 인식된 제품 정보와 가격·매장·분석 결과가 모두 비워지는지
- KREAM·POIZON 영수증이 '리셀' 구분으로 기록되는지
- 일반상품과 리셀 자동 메모가 기록 탭 및 엑셀에 저장되는지
