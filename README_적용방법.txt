리셀 PICK v6.12.4 적용 방법

1. ZIP의 파일을 app.py가 있는 GitHub 저장소 최상단에 전부 덮어씁니다.
2. GitHub Desktop에서 변경 파일을 모두 확인합니다.
3. Summary에 "리셀 PICK v6.12.4 클라우드 자동 저장·저장 오류 수정"을 입력합니다.
4. Commit to main → Push origin을 누릅니다.
5. Render가 Live가 된 뒤 /version.json에서 6.12.4를 확인합니다.
6. 설정 → 내 계정과 데이터 보관에서 클라우드 자동 저장을 처음 한 번 켜고 동의합니다.
7. 이후 기록·장바구니·영수증·메모·설정을 변경하면 자동 저장 완료 시각이 표시됩니다.

중요
- v6.12.2에서 정상화된 로그인 유지용 키 이름과 인증 구조는 변경하지 않았습니다.
- 원본 사진, 로그인키, 비밀번호, 분석 캐시는 자동 클라우드 저장 대상이 아닙니다.
- 다른 기기에서 먼저 변경한 경우 자동 덮어쓰지 않고 복원 안내를 표시합니다.
