리셀 PICK 소싱 계산기 WEB v5.5.3 통합본

이번 업데이트 핵심
- 사용에 문제가 없는 범위에서 OpenAI API 호출을 한 번 더 줄였습니다.
- 휴대폰 브라우저가 바코드를 직접 읽을 수 있으면 AI보다 먼저 무료 바코드 인식을 실행합니다.
- 이미 분석한 바코드·상품코드·상품명은 기기에 최대 1,500개까지 365일 저장합니다.
- 같은 상품을 다른 각도로 다시 촬영해도 바코드가 같으면 저장된 상품정보를 불러와 AI 호출 0회로 처리합니다.
- 동일 사진은 기존처럼 90일, 동일 키워드 분석은 30일 재사용합니다.
- 동시에 같은 분석 버튼을 여러 번 눌러도 중복 호출하지 않습니다.
- 일반상품·가격표·영수증 분석의 AI 응답 길이를 필요한 범위로 줄여 비용을 절감했습니다.
- 바코드 직접 인식을 지원하지 않는 기기에서는 기존 AI 분석으로 자동 전환되어 사용에는 문제가 없습니다.
- 계산, 수수료, 장바구니, 통계, 기록, 엑셀 기능은 API를 사용하지 않습니다.
- 429 잔액 부족 오류는 한국어 안내로 표시합니다.

기존 누적 기능
- 일반상품 쿠팡·네이버쇼핑 탭 분리 및 플랫폼별 설정
- KREAM·POIZON 리셀 탭과 플랫폼별 수수료 설정
- 사진·영수증 자동저장, 개별삭제·일괄삭제, 엑셀 다운로드
- 통계는 장바구니에 담은 상품만 집계
- 초기화 시 판매가·소싱가·순이익·키워드 분석 완전 초기화
- 자동 연결의 마지막 선택값 유지
- 초보자 사용법 안내

적용 방법
1. 기존 배포 폴더를 백업합니다.
2. 이 ZIP을 새 폴더에 압축 해제합니다.
3. 기존 저장소 파일 전체를 새 파일로 교체합니다.
4. GitHub Desktop에서 변경사항을 Commit 후 Push합니다.
5. Render 배포가 완료될 때까지 기다립니다.
6. 휴대폰에서 리셀 PICK을 완전히 종료한 뒤 다시 실행합니다.
7. 화면 상단 버전이 v5.5.3인지 확인합니다.
8. 이전 화면이 보이면 Chrome 설정에서 사이트 데이터를 삭제하거나 홈 화면 아이콘을 삭제 후 다시 추가합니다.

주의
- API 비용 절약은 반복 분석에서 가장 큰 효과가 있습니다.
- 처음 보는 새 상품은 정확한 상품정보 인식을 위해 AI가 1회 호출됩니다.
- 브라우저 로컬 저장 데이터를 삭제하면 저장된 상품 캐시도 함께 삭제됩니다.

[v5.5.3 추가]
- 설정 화면에서 이번 달 리셀 PICK API 예상 사용액, 설정 예산 잔여액, 실제 호출 횟수, 캐시 절약 횟수, 입력·출력 토큰을 확인할 수 있습니다.
- 월 API 예산은 OpenAI에 설정한 월 지출 한도와 같은 금액으로 직접 입력합니다.
- 앱 표시 금액은 이 기기에서 발생한 호출의 예상치이며, 실제 청구액과 크레딧 잔액은 OpenAI Usage 화면이 최종 기준입니다.
