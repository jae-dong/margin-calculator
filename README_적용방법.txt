리셀 PICK v6.11.1 적용 방법

1. 이 폴더 안의 파일을 기존 GitHub 프로젝트 폴더에 전부 덮어씁니다.
2. GitHub Desktop Summary에 아래 문구를 입력합니다.
   리셀 PICK v6.11.1 앱 종료 후 로그인 유지 긴급 수정
3. Commit to main을 누른 뒤 Push origin을 누릅니다.
4. Render 배포가 Live가 될 때까지 기다립니다.
5. 배포 주소 뒤에 /version.json을 붙여 6.11.1인지 확인합니다.
6. 휴대폰 앱을 완전히 종료한 뒤 다시 실행합니다.
7. 한 번 로그인한 다음 앱을 닫고 1~5분 뒤 다시 열어 로그인 유지 여부를 확인합니다.
8. 마지막 접속 후 1시간이 지나면 자동 로그아웃되는지 확인합니다.

중요: 기존 v6.11.0 파일 일부만 교체하지 말고 전체 파일을 덮어쓰세요.
