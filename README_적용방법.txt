리셀 PICK v6.11.2 적용 방법

1. 이 ZIP을 압축 해제합니다.
2. 기존 GitHub 프로젝트 폴더에 파일을 전부 덮어씁니다.
3. GitHub Desktop Summary: 리셀 PICK v6.11.2 로그인 유지 최종 보강
4. Commit to main → Push origin
5. Render가 Live가 되면 /version.json에서 6.11.2를 확인합니다.
6. 휴대폰 앱을 완전히 종료한 뒤 다시 열고 한 번 로그인합니다.
7. 뒤로가기로 종료한 후 1~5분 안에 다시 열어 로그인 유지 여부를 확인합니다.

중요: 서버와 화면 파일을 일부만 올리지 말고 ZIP 내부 파일 전체를 덮어써야 합니다.
