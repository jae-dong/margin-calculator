리셀 PICK v6.9.2 로그인 세션 유지 긴급 수정

수정 내용
- 관리자 계정 로그인 후 즉시 로그아웃으로 돌아가던 문제 수정
- 쿠키가 차단되는 설치형 앱/인앱 브라우저에서도 보안 로그인 토큰으로 세션 유지
- 로그인 요청 credentials include 적용
- API 응답을 서비스워커가 캐시하지 않도록 수정
- 다른 기기 로그아웃/비밀번호 변경 시 기존 로그인 토큰 무효화
- 내 데이터 및 관리자 회원목록 다운로드에도 로그인 인증 적용

적용
1. 이 폴더의 파일을 기존 프로젝트에 모두 덮어씁니다.
2. GitHub Desktop에서 Commit 후 Push 합니다.
3. Render가 Live가 될 때까지 기다립니다.
4. 휴대폰 앱을 완전히 종료한 뒤 다시 실행합니다.
5. /version.json에서 6.9.2를 확인합니다.
