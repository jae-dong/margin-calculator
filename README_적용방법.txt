리셀 PICK v6.12.5 적용 방법

1. ZIP 파일의 압축을 풉니다.
2. ZIP 안의 모든 파일을 app.py가 있는 GitHub 저장소 최상단에 덮어씁니다.
3. GitHub Desktop Summary에 아래 문구를 입력합니다.
   리셀 PICK v6.12.5 로그아웃 설정 화면 정리
4. Commit to main 후 Push origin을 누릅니다.
5. Render가 Live가 된 뒤 /version.json에서 6.12.5를 확인합니다.
6. 로그아웃 상태에서 설정 탭을 열어 서비스 안내 아래의 데이터 관리·공통 계산 설정이 보이지 않는지 확인합니다.
7. 로그인 후 두 카드가 다시 표시되는지 확인합니다.
