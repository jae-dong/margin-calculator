리셀 PICK WEB v6.9.1 로그인 긴급 수정본

[이번 업데이트 핵심]
1. Render·Cloudflare 프록시 환경에서 정상 로그인 요청이 차단될 수 있던 호스트/HTTPS 판정 수정
2. 로그인 세션 쿠키가 실제 HTTPS 주소를 정확히 인식하도록 ProxyFix 적용
3. 관리자 계정의 손실된 관리자 권한·중지 상태·기존 잠금을 배포 시작 시 복구
4. 관리자 회원번호 100000 및 이메일 로그인 모두 지원
5. 회원번호 입력 시 모바일 전각 숫자, 공백, 하이픈을 자동 정리
6. 로그인 전에 서버와 PostgreSQL 연결 상태를 자동 확인
7. 로그인 실패 원인을 로그인창 안에 구체적으로 표시
   - 가입 계정 없음
   - 비밀번호 오류
   - 계정 잠금
   - 데이터베이스 연결 실패
   - 세션 생성 실패
   - Render 주소가 아닌 곳에서 실행한 경우
8. 서버 응답이 20초 이상 없으면 멈춘 화면 대신 연결 오류 안내
9. 로그인 성공 후 세션 유지 여부를 다시 확인
10. 서비스워커 캐시를 v6.9.1로 교체해 이전 로그인 코드가 남는 문제 방지
11. v6.9.0의 설정 탭 분리, 하단 탭 터치, 사진검색, 키워드 분석 개선 유지

[기존 프로젝트에 적용]
1. 이 ZIP을 별도 폴더에 압축 해제
2. RESALE_PICK_v6.9.1 폴더 안 파일 전체를 기존 margin-calculator 폴더에 덮어쓰기
3. GitHub Desktop에서 margin-calculator 저장소 선택
4. Summary에 아래 문구 복사
   리셀 PICK v6.9.1 로그인 긴급 수정
5. Commit to main
6. Push origin
7. Render 배포가 Live가 될 때까지 기다리기
8. Render 주소 뒤에 /version.json을 붙여 6.9.1 확인
9. 휴대폰의 리셀 PICK을 완전히 종료한 후 다시 실행

[Render Environment 필수 확인]
- DATABASE_URL
- SECRET_KEY
- ADMIN_EMAILS: 관리자 가입 이메일
- OPENAI_API_KEY

[로그인 확인 순서]
1. 설정 → 로그인
2. 로그인창에 '이메일 또는 회원번호와 비밀번호를 입력해 주세요.'가 나오면 서버 연결 정상
3. 관리자 이메일 또는 회원번호 100000 입력
4. 기존 가입 비밀번호 입력
5. 성공하면 설정 탭의 운영자 관리 화면으로 자동 이동

[주의]
- PostgreSQL 회원정보·약관 동의·클라우드 데이터는 삭제되지 않습니다.
- 관리자 비밀번호 자체를 임의로 바꾸지는 않습니다.
- 비밀번호가 실제로 기억나지 않는 경우 이메일 비밀번호 찾기 기능과 SMTP 설정이 필요합니다.
- GitHub Pages 주소가 아니라 Flask/Render로 배포된 앱 주소에서 로그인해야 합니다.
