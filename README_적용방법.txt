리셀 PICK WEB v5.9.0

[이번 업데이트]
- 이메일 회원가입·로그인 베타 기반
- 비밀번호 안전 해시 저장
- 사용자별 클라우드 데이터 분리
- 현재 기기 데이터의 클라우드 저장·복원
- 로그인 상태와 계정 정보 표시
- 기존 v5.8.0 요금제 제공량 및 모든 소싱 기능 유지

[중요: 정식 판매 전 필수]
1. Render 환경변수 SECRET_KEY에 충분히 긴 임의 문자열을 등록하세요.
2. 현재 기본 저장소는 SQLite입니다. Render 무료 인스턴스의 파일은 재배포·재시작 때 사라질 수 있으므로 실제 고객을 받기 전 PostgreSQL 또는 Render Persistent Disk로 변경해야 합니다.
3. 현재는 베타 계정 기반으로 이메일 인증, 비밀번호 찾기, Google 로그인, 결제 검증은 아직 연결되지 않았습니다.
4. 개인정보처리방침에 회원 이메일, 저장 데이터, 보유기간, 서버 제공업체를 최종 반영해야 합니다.

[실행]
pip install -r requirements.txt
python app.py
브라우저에서 http://localhost:10000 접속
