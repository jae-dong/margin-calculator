리셀 PICK v6.11.9 검증 내역

확인한 기존 문제
- 인증 토큰·복원 토큰·장치키·resume 키가 동시에 동작해 실패 경로가 서로 충돌함
- 시작 인증 실패 시 최대 3회 자동 재시도와 pageshow·visibilitychange 재호출이 겹쳐 화면이 여러 번 깜박임
- 서비스워커 controllerchange가 추가 새로고침을 발생시킬 수 있었음
- 한 인증 경로가 실패하면 다른 저장정보까지 삭제되어 재접속 시 로그인창으로 돌아갈 수 있었음

v6.11.9 변경
- localStorage 단일 서명 인증 토큰을 로그인 유지의 주 경로로 사용
- 서버는 토큰의 세션 ID와 DB의 마지막 활동시간을 확인해 1시간 미접속 시에만 만료
- 시작 시 /api/account/me를 한 번만 호출
- 3회 자동 재시도·다중 복원키·서비스워커 강제 재로드 제거
- 토큰 저장 직후 localStorage 재읽기로 실제 저장 성공 여부 검증
- 로그인 유지 실패 시 토큰 원문 없이 상태코드와 저장 여부만 안내

자동 검사
- app.py Python 문법 컴파일 통과
- index.html JavaScript node --check 통과
- HTML 중복 ID 없음
- 삭제한 구형 인증 함수 참조 없음
- 인증 VM 검사: 로그인 토큰 저장 → 새 실행 컨텍스트에서 복원 → /api/account/me 1회 호출 → 로그인 상태 복원 통과
- 화면·서버·manifest·service worker·version.json 실제 버전 6.11.9 확인
- ZIP 무결성 검사 통과

제한
- 이 작업 환경의 Chromium은 관리자 정책으로 로컬·파일 URL 실행이 차단돼 실제 삼성 인터넷/폴드폰 자동 브라우저 테스트는 실행할 수 없었습니다. 최종 실기기 확인은 Render 배포 후 필요합니다.
